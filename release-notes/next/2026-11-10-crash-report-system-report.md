- **Launcher crash reports say how the run ended.** After the launcher closed without being closed, Send Report now adds what Windows Error Reporting kept of it (the module that faulted and the exception code, with the report file to attach) or Linux's core dump of it (the signal and the crashed thread), or the kernel's out-of-memory kill, and says so when the system kept nothing. Each line of the last seconds also has the launcher's memory.
