- **Install with Scoop or winget.** On Windows, `scoop bucket add anytogether https://github.com/AnyTogether/scoop-bucket` then `scoop install anytogether/anyps5-desktop` installs the portable zip with a Start menu shortcut. `winget install AnyTogether.AnyPS5Desktop` installs the installer once its submission to winget's repository is accepted (pending review). With Scoop, turn off **Settings → Behaviour → Check for updates** and update with `scoop update anyps5-desktop`, since the launcher's own update would install a second copy. On Arch Linux, the `anyps5-desktop-bin` package is in [AnyTogether/linux-packages](https://github.com/AnyTogether/linux-packages) (not on the AUR yet). The Scoop manifest and the Arch package follow each stable release by themselves.
