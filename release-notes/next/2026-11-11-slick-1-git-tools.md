- **Update from Git says everything it needs at once, and how to install it.** When build tools were missing, Update from Git named one, and after you installed it, the next. Now it looks for all of them before it pulls anything (Git, CMake and, for a checkout without a build folder, Ninja and the C and C++ compilers, plus the X11 development files on Linux) and lists every missing one together. Under the failure there is the command that installs them, ready to copy: winget on Windows (WinLibs GCC 15.2, which brings gcc, g++, CMake and Ninja), Scoop where only Scoop is installed, and apt, dnf or pacman on Linux. On Windows, WinLibs and Ninja install for your user only, so the launcher can also run that command itself and show what it prints. Commands that need administrator rights (Git's installer, sudo on Linux) are only ever shown to copy. Check again looks for the tools again without restarting AnyPS5: on Windows it reads PATH anew, so what you just installed is found. On an Ubuntu whose own GCC is older than 12, gcc-12 and g++-12 are used when they are installed, as the build guide does. Reported by Slick Daddy.
