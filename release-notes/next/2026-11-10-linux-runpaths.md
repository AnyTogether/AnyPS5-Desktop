- **No build folders in the Linux packages' library paths**: some plugin libraries in the .deb, the AppImage and the .tar.gz kept the release build machine's folders (`/home/runner/...`) in their RUNPATH, which namcap reports as insecure, as a folder by that name could hand them other libraries. The packaging now leaves every bundled library looking only beside itself and in the bundle (`$ORIGIN`), and every change checks that no library in the bundle, the .deb, the AppImage or the .tar.gz looks anywhere else.
