- **The PS2 emulator is a download of its own.** Once an emulator host release ships LRPS2, Settings ›
  Emulators shows Download the PS2 emulator right under the PS1 emulator, so a player who plays only
  PS1 games never downloads it. It comes from the same signed release as the PS1 emulator, is
  checked with it before every game, and updates with it. The first time it is added, Run PS2 games
  in the separate host turns on. Remove the PS2 emulator deletes it again and keeps the PS2 BIOS,
  memory cards and save states. The signed PS1 emulator published so far (1.0.0) has no PS2
  emulator, so nothing changes until a host release with one is out.
