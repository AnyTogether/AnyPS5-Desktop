- **Save states for PS1 and PS2 games in the launcher's window.** With an emulator host that saves states, the PS button's game menu has Save state and Load state: eight slots per game, each with the date and time it was saved and a small picture of that moment. Saving over a slot asks first, and a state made by another version of the emulator or from another game is refused with a plain message. Loading a PS1 state also puts its memory card back to that moment. Each game keeps its states in its own folder in the launcher's data folder, next to the memory cards, so two games whose discs have the same file name never share a slot. They are for playing alone, and nothing online uses them. The signed PS1 emulator published so far does not save states, so these rows show only once a host release that does is installed.
