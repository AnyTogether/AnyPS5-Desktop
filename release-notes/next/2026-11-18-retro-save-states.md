- **Save states for PS1 and PS2 games in the launcher's window.** With an emulator host that saves states, the PS button's game menu has Save State and Load State: eight slots per game, each with the date and time it was saved and a small picture of that moment. Saving over a slot asks first, and a state made by another version of the emulator or from another game is refused with a plain message. Loading a PS1 state also puts its memory card back to that moment. The states are kept per console in the launcher's data folder, next to the memory cards. They are for playing alone; nothing online uses them. The signed PS1 emulator published so far does not save states, so these rows show only once a host release that does is installed.
