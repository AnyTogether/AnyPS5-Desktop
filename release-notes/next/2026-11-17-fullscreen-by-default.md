- **New installs start games in full screen.** A launcher that starts for the first time opens games in full screen: Settings › Default Display starts as Full Screen. A launcher that already had settings keeps what it did, so its games still open in a window: nothing switches by itself on update. Choose Full Screen in Settings › Default Display to move every game that made no choice of its own, or in a game's own Game Settings › Display; choose Window in the same places to go back. A game that chose Window or Full Screen before keeps its choice (Game Settings › Use default display makes a game follow Default Display again). With upstream's engine the launcher only presses F11 when the game's window is not full screen yet. On Linux this only works on X11: on Wayland the launcher cannot change the window, so the default has no effect there.
