- **Settings › Emulators can download the PS1 emulator.** With emulator games turned on, a new row downloads the AnyPS5 emulator host with SwanStation from its signed releases, so PS1 games can play in the launcher's own window. Nothing is downloaded until you select it. The download's signature and every file are checked before it is installed, and the files are checked again before every game; a host that fails is not started and is offered again. Until the first signed release is published, the row says none is available yet.
