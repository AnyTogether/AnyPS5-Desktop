- **A module the dump holds twice no longer spoils the unlock.** Some dumps carry the same module in two folders: a `decrypted/sce_module` folder beside `sce_module` (Lost in Play), or `.prx` files next to `eboot.bin` that `sce_module` holds too (Minecraft). The relinker refuses two modules with one name. On older engines the unlock stopped with "Conflicting guest output filename". On newer ones it went on with the wrong copy, and Lost in Play stopped as it started. AnyPS5 now takes one copy of each such module, the one in `sce_module` first, and the unlock log names the copy it set aside. Every other module is converted where the dump has it, as before. For a game that failed this way, choose ⋯ → Unlock Again. Thanks to Slick Daddy for the report and its log, and to Lenny4250gh for tracking down the Minecraft case and proposing a fix.
