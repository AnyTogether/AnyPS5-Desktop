- **A tap on a direction no longer skips a game when the launcher freezes for a moment.** If the interface stalled right after the press (for example while a big background picture was being drawn), the key's release stayed queued behind the freeze, the hold's repeat timer ran out first and moved the selection once more, so Game 1 jumped to Game 3. A repeat that fires long after it was due is now dropped and the wait starts over, for the keyboard and the controller alike; a direction really still held goes on repeating.
