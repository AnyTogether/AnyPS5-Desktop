- **PS1 and PS2 games in the launcher's window can be drawn sharper.** The game's menu (PS button) has a new setting on its Graphics page, Internal resolution: Native, 2x, 3x or 4x for a PS1 game, and Native, 2x or 4x for a PS2 game. It lists only the values the emulator can show, and the choice is kept for later games of that console. A PS1 game changes in a moment. A PS2 game changes the next time it starts. If the emulator cannot show a value you saved, the game uses the largest one it can and the row says so. The row shows only while the emulator draws on the graphics card, and for PS2 games only with an emulator host that limits the PS2 resolution. Higher values need a faster graphics card.
