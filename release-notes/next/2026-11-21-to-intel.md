- **Games no longer stop with SIGILL on an Intel CPU.** The PS5 has an AMD processor, and games use instructions only AMD processors have (MONITORX/MWAITX, CLZERO, RDPRU, SSE4a). The launcher now relinks with `--to-intel` on any computer whose CPU is not AMD's, which rewrites them, as the engine's own guide says to. **Advanced › Rebuild options › Convert for Intel CPUs** turns it off or on for one game. A game already unlocked keeps its old build until you unlock it again. If the relinker cannot convert a game, it is unlocked without the conversion and the unlock log says so.
