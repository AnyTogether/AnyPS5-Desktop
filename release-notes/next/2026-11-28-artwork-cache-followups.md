- **Artwork cache follows library changes while the launcher is open.** A background replaced on disk (same path, new size or modification time) is re-copied instead of showing the old lighter image until the next start. Copies of games that left the library, or of pictures that were replaced, are deleted from the cache after a scan so they do not accumulate.
- **Backgrounds that are already light enough are not read in full only to be left alone.** The PNG header (33 bytes) is enough to decide; a 4K file is opened only when a lighter copy is actually needed.
- **A background whose lighter copy is already ready is drawn without an extra fade.** Home’s cross-fade remains the only transition; the copy does not start at opacity 0 again when it was ready at the first build (and the drift scale is not interrupted by an opacity layer).
