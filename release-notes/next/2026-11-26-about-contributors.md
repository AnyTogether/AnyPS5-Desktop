- **Settings › About shows the people who build the launcher.** The owner (Utku Halis) is listed first with their GitHub avatar. Under that, the other contributors appear as a grid of floating avatars with commit counts; each opens that person's GitHub profile, from the mouse, the keys (← → and Enter) or a controller. "See all on GitHub" opens the full contributors graph. The list is loaded from the public GitHub API and falls back to the owner alone when offline.
