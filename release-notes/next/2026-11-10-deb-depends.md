- **The .deb names every library the launcher needs**: 0.1.20's Depends left out the libraries the bundled SDL2 links (ALSA, Wayland, xkbcommon, Xcursor, Xi, Xinerama and the rest), so on a system without them SDL2 could not load and controllers fell back to the older reader. The packaging now stops when a linked library has no package to name, Ubuntu 24.04's renamed packages are listed as alternatives (`libasound2 | libasound2t64`), and every change installs the .deb on clean Ubuntu 22.04 and 24.04 and checks that the launcher and each library it carries find everything they link.
