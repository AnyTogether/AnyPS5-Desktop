- **Scoop and Arch package copies leave updates to their package manager**: the launcher sees when Scoop installed it (its app folder, also under a custom `SCOOP` or `SCOOP_GLOBAL` root) or when pacman owns it (`anyps5-desktop-bin`). It still checks for updates when **Settings → Behaviour → Check for updates** is on, but instead of downloading and running the installer, which under Scoop put a second copy in `%LOCALAPPDATA%\Programs\AnyPS5 Desktop`, it says a new version is out and how to get it: `scoop update anyps5-desktop` (Settings › About copies the command), or your package manager on Arch. These copies follow the stable releases, so Update Channel is not shown for them. The installer, the zip, the AppImage, the .deb and winget update as before.
