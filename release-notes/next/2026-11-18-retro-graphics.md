- **PS1 and PS2 games in the launcher's window look better from the start, and have a Graphics page.** The game's menu (PS button) has a new Graphics row after Audio. Its page holds Internal resolution, which moves there from the menu's first page and now also offers 6x and 8x for a PS1 game and 8x for a PS2 game, for the strongest graphics cards, and, for a PS1 game, Smooth textures (Off, Smooth or Extra smooth), Fix wobbly 3D and Widescreen, or for a PS2 game, Sharper textures and Widescreen. Each lists only what the emulator offers, and a choice is kept for later games of that console. A PS1 game now starts with wobbly 3D fixed, the console's dithering removed, and smooth textures from 2x up. A PS2 game starts with sharper textures. Widescreen stays off unless you turn it on. On PS1 it can make 2D games and drawn backgrounds look wrong, and on PS2 it works only for games the emulator has a widescreen patch for and changes the next time the game starts. Settings that do not work in the launcher or only trade accuracy are hidden, among them PS2's VR, its manual hardware fixes and its CPU tuning, and a value an earlier version saved for one is no longer used.
