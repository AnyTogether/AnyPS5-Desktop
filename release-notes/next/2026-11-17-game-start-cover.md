- **A game starts from its cover.** While a game loads, the launcher shows its artwork with its name and the moving line. Once the game is ready the cover goes away — it never stays while you play. In full screen, on Windows the cover waits until the game's window has opened and settled, then fades over the game; on Linux the Flutter cover fades. In a window the cover stays on the launcher home and fades out there (no overlay on the game). Turn it off in Settings › Default Display › Start animation, or per game in Game Settings › Start animation. With reduced motion the fade is very short.
