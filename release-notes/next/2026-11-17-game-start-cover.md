- **A game starts from its cover.** While a game loads, the launcher shows its artwork with its name and the moving line. Once the game is ready the cover goes away — it never stays while you play. The cover appears opaque at once (home no longer shows through during the entrance). In full screen, on Windows the cover picture is prepared while the game starts and is placed over the game the moment its window appears, then fades (no flash of the desktop or taskbar, no abrupt jump of the game window); on Linux the Flutter cover fades. In a window the cover stays on the launcher home and fades out there (no overlay on the game). Turn it off in Settings › Default Display › Start animation, or per game in Game Settings › Start animation. With reduced motion the fade is very short.
