- **A game starts from its cover.** While a game opens, the launcher shows its artwork over the whole window with its name and the moving line. On Windows the cover stays until the game's window is open and has taken its size or full screen, then fades away over the game so there is no jump from a small window to full screen. On Linux the cover itself fades (there is no layered window over the game). The launcher steps aside (Hide the launcher while a game runs) after that. The fade is only for games that start in full screen: turn it off for all games in Settings › Default Display › Start animation, or per game in Game Settings › Start animation (both shown only in full screen). In a window, or with it off, the cover shows while the game opens and goes as soon as the game has started. With reduced motion the fade is very short.
